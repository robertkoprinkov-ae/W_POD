W_POD.ansatz#

The ansatz (a list of modes), the configuration of one optimisation stage, the objective, and the variable scaling.

Ansatz#

class Ansatz(modes)#

A sum of modes with a block-structured parameter vector.

Parameters:

modes (list) – Mode instances. All must share the same mesh.

n_param()#

Length of the full parameter vector.

n_coeff()#

Total number of trajectories over all modes.

get_param_pytree()#

List with one set of parameter names per mode. Checked against OptimPhaseGradConfig.

get_coeff_pytree()#

List with one set of coefficient (trajectory) names per mode. Checked against OptimPhaseCoeffConfig.

split_params_arr_by_mode(params_arr)#

List of per-mode blocks.

arr_to_dict(params_arr)#

Flat vector → list (one entry per mode) of dicts keyed by parameter name.

dict_to_arr(params_dict_per_mode)#

Inverse of arr_to_dict(): concatenate the per-mode dicts into the flat vector.

get_bounds_arr()#

Concatenated (lb, ub) of all modes.

get_constraints()#

All modes’ linear constraints, padded into the full vector.

Returns:

scipy.optimize.LinearConstraint with keep_feasible=False.

get_values_grid(z, params_arr)#

Reconstruction on the data mesh: the sum of the modes’ get_values_grid().

get_values_nodes(z, params_arr)#

Concatenated point clouds (positions, masses) of all modes, for the W term.

get_values_grid_exact(sol_dict_per_mode)#

Reconstruction from trajectory values (synthetic data).

write_hdf5(params_arr, hdf5_group)#

Write params_arr and one group mode_<i> per mode.

Stage configuration#

class LossWeights(l2, w2, penalty_exceed, reg_norm_pod, normalize, frobenius_or_l2_squared=2.)#

Weights of the objective’s terms.

Parameters:

  • l2 (float) – \(w_{L^2}\).

  • w2 (float) – \(w_W\). If 0 the W term is not computed.

  • penalty_exceed (float) – weight of the overshoot penalty AnsatzConfig.calc_exceed_training().

  • reg_norm_pod (float) – weight of AnsatzConfig.calc_pod_norms_reg().

  • normalize (bool) – divide the L2 and W terms by their stage-start values.

  • frobenius_or_l2_squared (float) – exponent \(q\) applied to each snapshot’s squared \(L^2\) error before summing. All final runs pass 1., giving \(\sum_j \Delta x\lVert D_j - U_j\rVert^2\). The default 2 is not what the runs use.

write_hdf5(grp)#

Store the weights as weight_l2, weight_w2, weight_penalty_exceed, weight_reg_norm_pod, weight_normalize and weight_frobenius_or_l2_squared in the HDF5 group grp.

class W2Config(tau_a, tau_b, rescale)#

Settings of the OT term.

Parameters:

  • tau_a (float) – OTT marginal relaxation of the reconstruction (1 = balanced).

  • tau_b (float) – same for the snapshot.

  • rescale (bool) – normalise the reconstruction’s masses to sum 1.

class OptimPhaseGradConfig(ansatz, grad_cfg)#

Per mode, per parameter and per loss term: does the parameter receive gradient from that term?

Parameters:

grad_cfg – list (one per mode) of {param_name: {'l2': bool, 'w1': bool}}.

Raises:

AssertionError – the keys do not match the ansatz.

Implemented with jax.lax.stop_gradient in AnsatzConfig.cut_grad(). A parameter excluded from both terms still moves through the regularisation and the constraints.

grad_cfg#

The configuration list passed to the constructor.

write_hdf5(grp)#

One boolean dataset <mode>_<param>_<term> per entry.

class OptimPhaseCoeffConfig(ansatz, coeff_cfg)#

RKHS-norm weights \(\lambda\).

Parameters:

coeff_cfg – list (one per mode) of {coeff_name: float}.

Raises:

AssertionError – the keys do not match the ansatz’s coefficient names.

coeff_cfg#

The configuration list passed to the constructor.

write_hdf5(grp)#

One dataset <mode>_<coeff> per weight.

AnsatzConfig#

class AnsatzConfig(data, weights_loss, w2_config, ansatz, ansatz_grad, ansatz_coeff_reg, variable_scaling_method='identity')#

Everything that defines one optimisation stage’s objective.

Parameters:

  • data – data object (x, dx, data_z, data_exact).

  • weights_loss (LossWeights)

  • w2_config (W2Config)

  • ansatz (Ansatz)

  • ansatz_grad (OptimPhaseGradConfig) – must refer to the same ansatz.

  • ansatz_coeff_reg (OptimPhaseCoeffConfig) – must refer to the same ansatz.

  • variable_scaling_method (str) – 'identity' or 'hessian'.

Note

The cost methods are jitted with self static. Do not change the attributes of a config after its first evaluation (Known issues and pitfalls).

l2_standard#

Stage normalisation \(L^2_0\) of the L2 term. None until update_scaling() has run.

w2_standard#

Stage normalisation \(W_0\) of the W term. None until update_scaling() has run.

rescale_params#

The ParameterRescaling of this config.

Loss terms

calc_l2(z, params_arr, sol_exact)#

\(\Delta x \sum_x (D(p;z) - U)^2\) for one snapshot.

calc_l2_training(params_arr)#

\(\sum_j \ell_j^{\,q}\) with \(\ell_j\) = calc_l2() of snapshot \(j\), vmapped over the snapshots.

calc_w1(z, params_arr, sol_exact, return_full=False, use_danskin=None)#

Entropic OT cost (reg_ot_cost) between the reconstruction’s point cloud and the snapshot (see Numerical methods), or +inf when that cost is negative (a diverged Sinkhorn solve).

Parameters:

  • use_danskin – False forces implicit differentiation (ridge_kernel=1e-6) with a linear solver chosen from the dtype at trace time: LUSolver() in fp32, GuardedNormalCG() in fp64. Anything else uses OTT’s default, which is Danskin.

  • return_full (bool) – also return the OTT output object.

calc_w1_training(params_result, use_danskin=None)#

Sum of calc_w1() over the snapshots (power 1, no square root).

calc_w1_div(z, params_arr, sol_exact, return_full=False)#

Sinkhorn divergence alternative to calc_w1(). Not used.

calc_reg(params_arr, verbose=False)#

\(\sum_c \lambda_c\, a_c^\top K_c a_c\). With verbose it also returns the per-mode breakdown.

calc_exceed(z, params_arr, sol_exact)#

Overshoot penalty of one snapshot, \(\Delta x \sum \max(D - U, 0)^2\).

calc_exceed_training(params_arr)#

Sum over the snapshots of calc_exceed() squared, so the overshoot enters to the fourth power (Known issues and pitfalls).

calc_pod_norms_reg(params_arr)#

\(\sum_i (\Delta x \lVert\varphi_i\rVert^2 - 1)^2\).

cut_grad(params_arr, loss_term_name)#

Copy of params_arr with stop_gradient on the blocks that OptimPhaseGradConfig excludes from loss_term_name ('l2' or 'w1').

Objective

_cost(params_arr, normalize_l2, normalize_w2, use_danskin=None)#

The stage objective in unscaled variables:

  w_l2 * L2(cut_grad(p,'l2')) / normalize_l2
+ w_w2 * W (cut_grad(p,'w1')) / normalize_w2
+ calc_reg(p) + w_exceed * exceed(p) + w_pod * pod_norm_reg(p)

If weights_loss.w2 == 0 the W term is skipped and L2 is divided by l2_standard.

_cost_scaled(params_arr, norm_l2, norm_w1, scaling_x)#

_cost(params_arr * scaling_x, norm_l2, norm_w1) (jitted).

cost_jit_scaled(params_arr)#

Objective in the scaled variables \(y = p / s\) that the optimiser sees, using the current l2_standard, w2_standard and scaling.

cost_jit_scaled_grad(params_arr)#

Gradient of cost_jit_scaled() with respect to the scaled variables.

rel_error_scaling_factor()#

\(S = \Delta x \sum_j (\sum_x U_j^2)^{q}\). With \(q = 1\) this is the squared Frobenius norm of the data, so \(\sqrt{L^2/S}\) is the relative error.

update_scaling(params_arr)#

Start-of-stage normalisation: \(L^2_0 = \max(L^2(p), 10^{-4} S)\), \(W_0 = \max(W(p), 10^{-3})\). Then calls ParameterRescaling.reset_scaling().

get_bounds_arr()#

The ansatz bounds mapped to the scaled variables, (lb/s, ub/s).

get_constraints()#

The ansatz linear constraints mapped to the scaled variables (\(A \to A\,\mathrm{diag}(s)\)).

write_hdf5(params_arr, file)#

Ansatz blocks, plus a group ansatz_cfg with the loss weights and the grad and reg subgroups.

ParameterRescaling#

class ParameterRescaling(ansatz_cfg, cost, calc_l2_training, calc_w1_training, method='identity')#

Diagonal change of variables \(p = s \odot y\).

Parameters:

method (str) – 'identity' (\(s = 1\)) or 'hessian'.

scaling_x#

The vector \(s\).

reset_scaling(x0)#

With 'hessian': compute the Hessian diagonal \(h\) of ansatz_cfg._cost at x0 with calc_hessian_diag_band(), then set \(s = 1/\sqrt{\max(|h|, 10^{-6}\max|h|)}\), so \(s_{\max}/s_{\min} \le 10^3\). No geometric-mean normalisation is applied.

scaled_to_unscaled(x)#

\(p = x \cdot s\).

unscaled_to_scaled(x)#

\(y = x / s\).

unscaled_to_scaled_bounds(lb, ub)#

\((lb/s,\ ub/s)\). Infinite bounds stay infinite.

unscaled_to_scaled_constraints(constraints)#

New LinearConstraint with \(A\,\mathrm{diag}(s)\) and the same bounds.

_hess_diag_exact(cost, params, norm_l2, norm_w1)#

Exact diagonal, one HVP per parameter (use_danskin=False). Diagnostic, not called.

_hess_exact(cost, params, norm_l2, norm_w1)#

Full Hessian, row by row. Diagnostic, not called.

_hess_diag(f, *args, key, argnums=0, n_samples=256, chunk=8)#

Hutchinson (Rademacher) estimate of the diagonal. Not called.

LUSolver(**kwargs)#

Factory returning lineax.LU(). It accepts and ignores the rtol/atol that OTT passes. Used as nonsym_solver of the implicit differentiation in fp32.
