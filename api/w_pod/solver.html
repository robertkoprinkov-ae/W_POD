W_POD.solver#

Drive SciPy over one or several stages.

class OptimCfg(stop_if_linesearch_fails, verbose, log_w1, maxiter, scipy_optim_method, callback_prefix='')#

Options of one stage.

Parameters:

  • stop_if_linesearch_fails (bool) – stored, not used.

  • verbose (bool) – print an Iter line per callback.

  • log_w1 (bool) – also evaluate and log the W term in the callback. This costs an extra OT solve per iteration.

  • maxiter (int) – SciPy maxiter.

  • scipy_optim_method (str) – e.g. 'SLSQP' (final runs), 'L-BFGS-B' (bounds only), 'trust-constr'.

  • callback_prefix (str) – prefix of the log lines.

class L2_W1_optimizer(data, ansatz_cfg, optim_cfg)#

One stage.

solve_scipy(initial)#

  1. update_scaling() at initial (loss normalisation and Hessian scaling);

  2. scipy.optimize.minimize on cost_jit_scaled() with its gradient, scaled bounds, scaled linear constraints and options={'maxiter': maxiter, 'maxcor': 50};

  3. stores result (the OptimizeResult) and params_result (unscaled).

The callback logs per iteration:

Iter k; error: <objective>; l2: <L2> (norm: <L2_0>; normalized: ...);
w1: <W> (norm: <W_0>; normalized: ...;) reg: <reg>; rel: <sqrt(L2/S)>

and prints the per-mode regularisation every 50 iterations.

Warning

With SLSQP the callback sees the trial point (Numerical methods).

result#

SciPy OptimizeResult of the stage (in scaled variables).

params_init#

Initial vector of the stage.

_log_l2#

Weighted L2 term per callback.

_log_w1#

Weighted W term per callback (only if log_w1).

_log_tot#

Objective per callback.

params_result#

Final parameter vector of the stage (unscaled).

calc_gradients_per_param(params_arr)#

Broken: calls the nonexistent ansatz_cfg.cost_grad. Use the IteratedSolver version.

filename()#

Broken: indexes OptimPhaseGradConfig directly.

write_hdf5(params=None, filename='data/output/params.hdf5')#

Writes the stage’s loss history (group loss: l2, w1, tot, norm_l2, norm_w2), the parameters and the configuration (HDF5 layout (params_k.hdf5, k ≥ 1)).

description_pretty()#

Human-readable list of which parameters see which term.

renormalize_losses(params_arr)#

Alias of update_scaling().

class IteratedSolver(data, ansatz_cfgs, optim_cfgs, n_iter)#

Run a list of stages, n_iter times over. Each stage starts from the previous stage’s result.

Parameters:

  • ansatz_cfgs (list) – one AnsatzConfig per stage, all with the same ansatz. The same object may be repeated.

  • optim_cfgs (list) – one OptimCfg per stage.

  • n_iter (int) – number of passes over the list.

solve_scipy(initial=None, directory_out=None)#

Run all stages. With directory_out (which must end with /) it writes params_0.hdf5 (the initial vector, params_arr only) and, after stage k, params_k.hdf5 through L2_W1_optimizer.write_hdf5(). It also prints SciPy’s success, message, status and nit per stage.

solve(initial=None)#

Broken: calls L2_W1_optimizer.solve, which does not exist.

filename()#

Broken: refers to a missing solvers_cfg attribute.

description_pretty()#

Broken: refers to a missing solvers_cfg attribute.

solvers#

One L2_W1_optimizer per stage.

params_result#

Final parameter vector (unscaled), i.e. the last stage’s result.

params_hist#

List of the parameter vectors after each stage.

calc_gradients_per_param(params_arr)#

Gradient of each stage’s scaled objective, split per mode and parameter. Used by the visualiser.

write_hdf5_every(directory='data/output/params_every/')#

Re-write every stage’s vector after the run.

HDF5 layout (params_k.hdf5, k ≥ 1)#

/                      attrs: description
/params_arr            full parameter vector (unscaled)
/mode_<i>/pod_local    (or pod_global)
/mode_<i>/beta_coeff   (alpha_coeff / gamma_coeff / gamma_shift_coeff ...)
/loss/{l2,w1,tot}      per-callback history of the stage (weighted)
/loss/norm_l2, norm_w2 stage normalisations L2_0, W_0
/ansatz_cfg/weight_*   LossWeights
/ansatz_cfg/grad/<mode>_<param>_<term>   OptimPhaseGradConfig
/ansatz_cfg/reg/<mode>_<coeff>           OptimPhaseCoeffConfig
