W_POD.two_dim.losses#

Loss terms (Losses) and the optimisation driver with variable scaling (Losses_scaled).

Losses#

class Losses(pts, dx, data_z, data_exact, ansatz, l2_or_l1=1, DOWNSCALED_SIZE=None, reg_lambda=0.)#
Parameters:

  • pts – grid nodes, (n_y * n_x, 2).

  • dx – grid spacing (the same in x and y).

  • data_z – snapshot parameters.

  • data_exact – snapshots, (n_z, H, W).

  • ansatz – a W_POD.two_dim.ansatz.Ansatz.

  • l2_or_l1 (int) – exponent applied to each snapshot’s squared error before summing (1 in the final runs).

  • DOWNSCALED_SIZE – if set, compute the W term on DOWNSCALED_SIZE² block averages (25 in the final runs).

  • reg_lambda (float) – weight of ansatz.get_reg in the objective (0 in the final runs).

bounds#

ansatz.get_bounds() (unscaled).

loss_l2(params, full=False)#

\(\sum_j \big(\Delta x^2 \sum (U_j - D_j)^2\big)^{q}\) with \(q\) = l2_or_l1, mapped over the snapshots with jax.lax.map (batch 50). With full it returns the per-snapshot values.

loss_w2_z(params, z_i, data_exact_flat, downscaled_size=None)#

The OTT output for snapshot z_i. The masses are |U| + pad and max(vals, 0) + pad with pad = 1e-6, each normalised to 1. With downscaled_size, masses and coordinates are block-averaged by H // downscaled_size and renormalised, and the solve uses threshold 1e-3 and use_danskin=False. Without it, threshold 1e-2 and OTT’s default use_danskin. In both cases \(\varepsilon = 0.1\) and at most 1e5 iterations.

loss_w2(params, downscaled_size=None, full=False)#

\(\sum_j\) reg_ot_cost of loss_w2_z() (vmapped).

get_l2_scaling_factor()#

\(\Delta x^2 \sum U^2\) (for l2_or_l1 = 1), so sqrt(loss_l2 / factor) is the relative Frobenius error.

_cost_sum(params, norm_l2, norm_w1, data_exact_flat, full=False)#

W / norm_w1 + L2 / norm_l2 + reg_lambda * ansatz.get_reg(params). With full it returns (l2, l2/norm_l2, w2, w2/norm_w1) per snapshot.

cost_sum(params, norm_l2, norm_w1, full=False)#

Jitted _cost_sum() on the stored data (full is ignored).

cost_sum_grad(params, norm_l2, norm_w1, full=False)#

Jitted gradient of _cost_sum() with respect to params (full is ignored).

_loss_l2(params, data_exact_flat, full=False)#

loss_l2() on explicitly passed data.

compute_l2_per_z_vmappable(z_i, params, data_exact_flat_row)#

\(\Delta x^2 \sum (U_j - D_j)^2\) for snapshot z_i.

_loss_w2(params, data_exact_flat, downscaled_size=None, full=False)#

loss_w2() on explicitly passed data.

w2_per_z_vmappable(z_i, params, data_exact_flat, downscaled_size)#

reg_ot_cost of loss_w2_z() for one snapshot (power 1). A cost that is not finite or is negative (a diverged Sinkhorn solve) is replaced by 1e10, so that the L-BFGS-B line search backtracks.

_downscale_array(arr, factor=2)#

Average non-overlapping factor × factor blocks of a stack of 2D arrays (N, H, W).

Raises:

ValueError – H or W not divisible by factor.

data_exact_flat#

Snapshots flattened to (n_z, H * W).

n_coord_frames#

Number of coordinate frames of the ansatz.

Losses_scaled#

class Losses_scaled(losses, params_init, data_exact, scaling='gradient')#

Optimise Losses in rescaled variables. The constructor already calls reset_scaling() at params_init.

Parameters:

  • losses (Losses)

  • params_init – starting vector (unscaled).

  • data_exact – snapshots, (n_z, H, W).

  • scaling (str) – 'hessian' (final runs), 'gradient' or 'identity'.

reset_scaling(params)#

  1. norm_l2 = loss_l2(params) and norm_w1 = loss_w2(params, DOWNSCALED_SIZE) (no floor);

  2. the scaling:

    • 'hessian': \(h\) from calc_hessian_diag_2d() (downscale_factor=20, unfloored), then \(s = 1/\sqrt{\max(|h|, 10^{-6}\max|h|)}\), divided by its geometric mean;

    • 'gradient': two scalars, the inverse gradient norms over the mode pixels and over everything else;

    • 'identity': \(s = 1\);

  3. re-jit the scaled cost and gradient.

optimize(params_init, maxiter, debug=False)#

One stage. reset_scaling() at params_init, then scipy.optimize.minimize(method='L-BFGS-B', options={'maxiter': maxiter, 'maxcor': 50}) with the bounds mapped to the scaled variables (infinite bounds kept). Prints one line per iteration and the time per iteration.

Returns:

the unscaled result, plus the OptimizeResult if debug.

convert_x(x)#

Scaled → unscaled: \(x \cdot s\) for 'hessian', otherwise the two gradient-norm factors applied to the mode pixels and to the rest.

convert_x_inv(x)#

Inverse of convert_x() (unscaled → scaled).

cost(x)#

Objective at the scaled vector x (JAX).

cost_grad(x)#

Gradient of cost() with respect to the scaled variables (JAX).

cost_np(x)#

cost() for NumPy input and output, as passed to SciPy. Prints W2PATCH: guarded cost ... when the value is not finite or is at least 1e6, i.e. when the guard of Losses.w2_per_z_vmappable() fired.

cost_grad_np(x)#

cost_grad() for NumPy input and output, as passed to SciPy. A gradient with non-finite entries is replaced by zeros (and a W2PATCH: non-finite gradient ... line is printed), so that the L-BFGS-B line search backtracks instead of stopping.

_cost_graddable(x, data_exact_flat)#

losses._cost_sum(convert_x(x), norm_l2, norm_w1, data_exact_flat), with the normalisations and scaling of the current stage.

mask_modal_variables(x)#

x with everything except the mode pixels set to 0.

mask_remainder(x)#

x with the mode pixels set to 0.

_hess_diag(f, *args, key, argnums=0, n_samples=256, chunk=8)#

Hutchinson (Rademacher) estimate of the Hessian diagonal. Not called.

norm_l2#

L2 normalisation of the current stage, \(L^2(p_0)\).

norm_w1#

W normalisation of the current stage, \(W(p_0)\).

scaling_x#

Scaling vector \(s\) ('hessian' only).

n_iter#

Iteration counter, cumulative over stages.

hist#

Objective value per iteration, cumulative over stages.

hist_grad_modes#

Gradient norm over the mode pixels per iteration (scaled variables).

hist_grad_remainder#

Gradient norm over all other parameters per iteration.

hist_params_rescaling#

Parameter vector at each reset_scaling().

iter_rescaling#

Value of n_iter at each reset_scaling().
