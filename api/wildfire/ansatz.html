W_POD.two_dim.ansatz#

The 2D ansatz is a hierarchy:

  • Ansatz is a sum over coordinate frames;

  • a CoordinateFrame is one coordinate transformation plus several modes that it transports together;

  • a transformation is a CoordinateTransformation (radial scaling plus rigid shift) or an IdentityCoordinateTransformation;

  • a Mode is a pixel field times an amplitude trajectory.

Every level has the same parameter-vector methods (n_param, get_bounds, split_params, split_params_recursive, get_params, get_params_recursive, get_reg). They are listed for each class below.

Interpolation#

interp2d_decay(xq, yq, x, y, f, k=1.0, asymptote=0.0, n_chunks=None)#

Interpolate the grid function f (shape (len(x), len(y))) at (xq, yq). Inside the box this is exactly interpax.interp2d(..., method='catmull-rom'). Outside, the value at the nearest boundary point decays toward asymptote as \(e^{-k s_x} e^{-k s_y}\), where \(s_x, s_y\) are the distances to the box.

The method ('catmull-rom') and the boundary join (C0, value only) are fixed inside the function. The function is wrapped in jax.checkpoint.

Parameters:

  • xq – query x-coordinates.

  • yq – query y-coordinates (same shape as xq).

  • x – grid x-coordinates (strictly increasing).

  • y – grid y-coordinates (strictly increasing).

  • f – values on the grid, shape (len(x), len(y)).

  • k (float) – decay rate outside the box (the code passes 15).

  • asymptote (float) – value far outside the box.

  • n_chunks – process the queries in this many sequential chunks (jax.lax.map) to cut peak memory.

Returns:

values, same shape as xq.

clamp(v, lo, hi)#

jnp.clip with a custom JVP whose gradient is 1 (not ½) for points exactly on the boundary.

_core_c0(xq, yq, x, y, f, method, k, a)#

C0 decay: one interp2d pass at the clamped point, times \(e^{-k s_x} e^{-k s_y}\). Used by interp2d_decay().

class CoordinateTransformation(n_discret_theta, rbf_radial_shifts, rbf_shift_x, rbf_shift_y, fix_center=False)#

Radial scaling about the centre of the grid, followed by a rigid shift:

\[p' = c + s(z) + r(\vartheta; z)\,(p - c), \qquad \vartheta = \operatorname{atan2}(p_y - c_y, p_x - c_x) \bmod 2\pi.\]

\(r(\cdot; z)\) is interpolated linearly and periodically between n_discret_theta equally spaced stations \(\vartheta_k = 2\pi k / n\). The value of station \(k\) is the trajectory rbf_radial_shifts.predict(z, radial_k_coeff) and is used directly as a scaling factor. The centre \(c\) is the centre of the bounding box of the points passed in, i.e. of the full grid in every call made by the code.

Parameters:

  • n_discret_theta (int) – number of azimuthal stations (24 in the final runs).

  • rbf_radial_shifts – interpolator shared by all stations.

  • rbf_shift_x – interpolator of the rigid shift \(s_x\).

  • rbf_shift_y – interpolator of the rigid shift \(s_y\).

  • fix_center (bool) – if true, \(s \equiv 0\). The shift coefficients stay in the parameter vector but have no effect.

theta_discret#

Station angles \(\vartheta_k\).

param_names#

['radial_0_coeff', …, 'radial_{n-1}_coeff', 'shift_x_coeff', 'shift_y_coeff'], the block order in the parameter vector.

n_param()#

n_discret_theta * rbf_radial_shifts.n_param() + rbf_shift_x.n_param() + rbf_shift_y.n_param().

get_bounds()#

(lb, ub): every radial coefficient (including its bias) \(\ge 10^{-4}\); the shift coefficients are free.

get_reg(params)#

Unweighted sum of the RKHS norms of all stations and both shifts. The weight is Losses.reg_lambda.

split_params(params)#

Dict from each name in param_names to its block.

split_params_recursive(params)#

Same as split_params() (this is a leaf).

get_params(params_split)#

Inverse of split_params().

get_params_recursive(params_split)#

Same as get_params().

transform(pts, z, params)#

Forward map of the points pts (shape (m, 2)), used for the W point cloud.

inv_transform(pts, z, params)#

Exact inverse, \(p = c + (p' - c - s)/r(\vartheta')\), with \(\vartheta'\) the azimuth of \(p' - c - s\). A radial scaling preserves the azimuth. Used to pull the data grid back for the L2 term.

get_shift_center(pts, z, params)#

\(c + s(z)\), the moving centre (plotted as a red cross).

plot_coeff(params, data_z, filename)#

Polar plots of \(r(\vartheta)\) per snapshot and the shift trajectories. Intended for a handful of snapshots.

Modes#

class Mode(n_pts, amplitude_fixed, rbf_amplitudes=None)#

A pixel field \(\varphi\) (n_pts values, row-major \(n_y \times n_x\)) with amplitude \(\max(0, a(z))\).

Parameters:

  • n_pts (int) – number of pixels.

  • amplitude_fixed (bool) – if true, no amplitude trajectory (\(a \equiv 1\)).

  • rbf_amplitudes – interpolator of \(a(z)\).

param_names#

['mode', 'amplitude_coeff'], or ['mode'] if the amplitude is fixed.

n_param()#

n_pts, plus rbf_amplitudes.n_param() unless the amplitude is fixed.

get_bounds()#

(lb, ub) with every entry \(\ge 10^{-6}\), mode values and amplitude coefficients alike.

split_params(params)#

Dict {'mode': ..., 'amplitude_coeff': ...}.

split_params_recursive(params)#

Same as split_params() (this is a leaf).

get_params(params_split)#

Inverse of split_params().

get_params_recursive(params_split)#

Same as get_params().

get_mode(z, params)#

\(\max(0, a(z))\,\varphi\), or \(\varphi\) if the amplitude is fixed.

get_reg(params)#

RKHS norm of the amplitude trajectory. Fails if the amplitude is fixed (Known issues and pitfalls).

plot_coeff(vis, params, ax)#

Draw the pixel field in ax[0] and the amplitude trajectory in ax[1].

Coordinate frames#

class CoordinateFrame(pts, x_crds, y_crds, data_z, coordinate_transformation, modes, fixed=False)#

A transformation shared by several modes.

Parameters:

  • pts – grid nodes, shape (n_y * n_x, 2), in meshgrid order.

  • x_crds – 1D x-coordinates (length n_x).

  • y_crds – 1D y-coordinates (length n_y).

  • data_z – snapshot parameters.

  • coordinate_transformation – CoordinateTransformation or IdentityCoordinateTransformation.

  • modes (list) – Mode objects.

  • fixed (bool) – treat the frame as stationary even if the transformation is not the identity.

A frame is transported unless fixed is set or its transformation is the identity. Only transported frames are interpolated, and only their nodes move in the W term.

param_names#

['coordinate_transformation', 'mode_0', 'mode_1', …], the block order in the parameter vector.

n_x#

Number of grid points in x.

n_y#

Number of grid points in y.

n_param()#

Transformation parameters plus all modes’ parameters.

get_bounds()#

scipy.optimize.Bounds of the frame’s block.

get_reg(params)#

Transformation RKHS norms plus every mode’s amplitude RKHS norm.

split_params(params)#

Dict from each name in param_names to its flat block.

split_params_recursive(params)#

Nested dict: {'coordinate_transformation': {...}, 'mode_k': {'mode': ..., 'amplitude_coeff': ...}}.

get_params(params_split)#

Inverse of split_params().

get_params_recursive(params_split)#

Inverse of split_params_recursive().

calc_values(z, params_by_name)#

Sum of the frame’s modes on its own nodes (untransformed).

get_value_grid_arbitrary(params, z)#

The frame’s contribution on the data grid at parameter z. For a transported frame this is calc_shift_interpax(). Otherwise it is calc_values().

get_value_grid(params, z_i)#

get_value_grid_arbitrary() at snapshot index z_i.

get_value_nodes(params, z_i)#

(positions, values) for the W term: the forward-transformed nodes (or the fixed grid) and the summed mode values.

calc_shift_interpax(pts, z, params)#

Pull pts back with inv_transform and evaluate the summed modes there with interp2d_decay() (k=15). This is the path used by the final code.

calc_shift(pts, z, params)#

Alternative with a linear RegularGridInterpolator and zero fill outside. Not used.

plot_coeff(vis, params, filename_prefix)#

Write <prefix>_coord.png (transformation) and <prefix>_modes.png (modes and amplitudes).

Ansatz#

class Ansatz(coordinate_frames, data_z)#

Sum of coordinate frames.

Parameters:

  • coordinate_frames (list) – CoordinateFrame objects.

  • data_z – snapshot parameters.

param_names#

['coord_frame_0', 'coord_frame_1', …].

n_param()#

Sum over the frames.

get_bounds()#

scipy.optimize.Bounds of the full vector.

get_reg(params)#

Unweighted sum of all RKHS norms.

split_params(params)#

Dict from coord_frame_i to that frame’s flat block.

split_params_recursive(params)#

Nested dict down to the leaves: {'coord_frame_i': {'coordinate_transformation': {...}, 'mode_k': {'mode': ..., 'amplitude_coeff': ...}}}.

get_params(params_split)#

Inverse of split_params().

get_params_recursive(params_split)#

Inverse of split_params_recursive().

get_value_grid_arbitrary(params, z)#

Reconstruction on the data grid at parameter z (flat, length n_y * n_x): the sum over the frames.

get_value_grid(params, z_i)#

get_value_grid_arbitrary() at snapshot index z_i.

get_value_nodes(params, z_i)#

Concatenated point clouds of all frames, for the W term. With K frames the result has K * n_y * n_x points.
