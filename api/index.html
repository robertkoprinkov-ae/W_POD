Parameter-vector layout#

Both codes optimise one flat vector. Its blocks, in order:

1D (W_POD.ansatz.Ansatz), one block per mode, concatenated in mode order:

Mode

Block

GlobalMode

pod_global (N), alpha_coeff

TransportedMode

pod_local (N), beta_coeff, gamma_coeff

StretchedMode

pod_local (N), beta_coeff, gamma_shift_coeff, gamma_stretch_coeff

N is the number of mesh nodes. Each *_coeff block has RBF_interpol.n_param() entries: \(n_z\), plus one for the bias.

2D (W_POD.two_dim.ansatz.Ansatz), one block per coordinate frame. Inside a frame, the transformation comes first and the modes follow:

  • coordinate_transformation: radial_0_coeff … radial_{n-1}_coeff, shift_x_coeff, shift_y_coeff (empty for the identity);

  • mode_k: mode (one value per pixel, row-major \(n_y \times n_x\)), then amplitude_coeff unless the amplitude is fixed.
